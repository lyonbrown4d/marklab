title: 下载与安装
description: 选择适合你的 Marklab 安装包。
---

在[官网下载区](../../#download)选择平台。各平台独立更新，以下载区显示的版本为准。

## macOS

macOS 仅支持 Apple Silicon 芯片（M 系列），不支持 Intel Mac。

1. 下载并打开 DMG。
2. 将 Marklab 拖入 Applications。
3. 从 Applications 打开 Marklab。

也可以从 [GitHub Releases](https://github.com/lyonbrown4d/marklab/releases) 下载 ZIP 压缩包。

### 首次打开

当前 macOS 安装包未进行 Developer ID 签名或公证。如果系统拦截，在确认文件来自上面的官方仓库后，打开“系统设置 → 隐私与安全性”，找到 Marklab 的拦截提示并选择“仍要打开”。

当前 macOS 版本需要手动下载安装更新。

## Windows 与 Linux

Windows x64 选择 setup.exe 安装程序。Linux x64 选择 AppImage；其他分发格式可在对应 Release 中查看。

如果某个平台没有可用安装包，下载区会明确显示，不会跳转到其他架构的文件。

## 更新已有安装

安装新版并替换旧应用即可。笔记保存在原工作区，应用设置也会保留。

更新前可备份重要笔记。安装包旁的 `SHA256SUMS.txt` 可用来核对下载文件。
