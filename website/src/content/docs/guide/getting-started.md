---

Marklab 是本地优先的 Markdown 工作区。笔记保存在你的文件夹里，可以用富文本或源码编辑，也可以接入 Git 管理版本。

## 打开一个工作区

1. [下载并安装 Marklab](../installation/)。
2. 打开应用，从工作区菜单选择一个本地文件夹。
3. 在文件列表里打开或新建 Markdown 笔记。

工作区可以是已有的笔记目录，也可以是一个 Git 仓库。

## 写下第一篇笔记

在正文中直接输入文字。使用工具栏的编辑模式切换按钮，在富文本与源码之间切换。

```md
# 今天的想法

先写下来，再慢慢整理。

- 一个发现
- 一个问题
- 下一步要做的事
```

使用 `⌘S`（macOS）或 `Ctrl+S`（Windows / Linux）保存。文件仍是普通 Markdown，可以备份、同步，也可以用其他编辑器打开。
