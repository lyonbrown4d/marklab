title: Vim 模式

Vim 用于源码编辑器，包括 Markdown 源码、代码文件、代码块扩展编辑器和 Mermaid 源码。富文本正文使用原有编辑方式。

## 开启方式

- **全局默认**：“设置 → 编辑 → 源码编辑器”中开启 Vim。
- **当前标签页**：点击底部状态栏的 Vim 按钮，选择跟随全局、开启或关闭。

标签页独立设置在本次打开会话中有效，关闭标签页后清除。

## 模式与输入

状态栏显示 Normal、Insert、Visual 模式，并显示 `:` 命令与 `/`、`?` 搜索输入。按 Esc 返回 Normal，或取消当前命令。

状态栏隐藏时，命令输入保留在编辑器下方；代码块弹窗内的输入留在弹窗中。

## 保存与关闭

| 命令           | 行为                                   |
| -------------- | -------------------------------------- |
| `:w`、`:write` | 保存当前内容                           |
| `:q`、`:quit`  | 先处理待保存内容，再关闭当前源码标签页 |
| `:wq`、`:x`    | 保存成功后关闭当前标签页               |

保存失败时不会继续关闭。代码块弹窗存在未应用修改时，`:q` 会提示先保存；Mermaid 中的关闭命令会结束源码编辑。

## 快捷键

Vim 编辑器获得焦点时，优先处理 Vim 绑定。离开该编辑器后恢复应用快捷键。只读编辑器不会启用可修改内容的绑定。
