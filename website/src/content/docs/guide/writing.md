## 两种编辑方式

**富文本**适合日常写作，直接处理标题、段落、列表、表格和代码块。

**源码**适合查看 Markdown 标记、修改格式细节和编辑代码文件。使用工具栏中的编辑模式按钮切换。

编辑模式改变的是操作方式，笔记仍保存在同一个文件中。

## 一个文件夹，一个工作区

工作区对应本地文件夹。文件列表用于打开、整理笔记，标签页用于在多个文档之间切换。

最近工作区菜单可以重新打开常用目录。文件夹被移动或外部磁盘未连接时，需要恢复路径或重新选择目录。

## 搜索与快捷键

双击 Shift 打开全局搜索。使用 `⌘⇧L`（macOS）或 `Ctrl+Shift+L`（Windows / Linux）切换侧栏。

完整快捷键可在“设置 → 快捷键”中查看。

## 连接笔记

在笔记中插入指向其他笔记的链接，例如：

```md
接着阅读 [[下一步计划]]。
```

图谱视图用于查看笔记间的连接。它帮助浏览关系，文件仍由工作区中的目录管理。

## 专注模式

“设置 → 编辑”中的 Zen 模式可隐藏写作区外的界面；Focus 模式可弱化当前写作区域以外的内容。
