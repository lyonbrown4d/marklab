Choose your platform in the [website's download section](../../#download). Platforms release independently; check the version listed next to each installer.

## macOS

macOS supports Apple Silicon (M-series) Macs only. Intel Macs are not supported.

1. Download and open the DMG.
2. Drag Marklab into Applications.
3. Open Marklab from Applications.

A ZIP archive is also available in [GitHub Releases](https://github.com/lyonbrown4d/marklab/releases).

### First launch

Current macOS builds are not Developer ID signed or notarized. If macOS blocks the app, first verify that you downloaded it from the official repository above. Then open System Settings → Privacy & Security and use **Open Anyway** for Marklab.

Current macOS builds require manual downloads to update.

## Windows and Linux

Choose the setup.exe installer for Windows x64, or AppImage for Linux x64. Other package formats may be available in the corresponding release.

When an installer is unavailable, the download section says so. It does not redirect to another architecture.

## Updating

Replace the old application with the new version. Your notes stay in their workspace folders, and your settings are retained.

Back up important notes before updating. Use the release's `SHA256SUMS.txt` to verify downloaded files.
