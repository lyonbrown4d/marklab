# Vim 模式

在「设置 → 编辑 → 源码编辑器」开启 Vim，可设置所有标签页的默认行为。
底部状态栏的 Vim 按钮也提供全局开关和当前标签页开关。标签页可以跟随全局，
或在本次打开会话中独立开启、关闭；关闭标签页后独立设置会清除。

Vim 适用于 Markdown 源码、代码文件、代码块扩展编辑器和 Mermaid 源码。
富文本正文保持现有编辑方式；只读编辑器不会启用可修改内容的 Vim 绑定。

底部状态栏显示当前编辑器的 Normal、Insert、Visual 模式，并承载 `:` 命令
和 `/`、`?` 搜索输入。状态栏隐藏时，输入保留在编辑器下方；代码块弹窗的
输入保留在弹窗内。按 Esc 返回 Normal 或取消命令、搜索输入。

| 命令           | 行为                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------- |
| `:w`、`:write` | 将编辑内容通过现有保存流程写入磁盘；代码块弹窗保持打开。                                 |
| `:q`、`:quit`  | 源码标签页先完成待保存内容再关闭；Mermaid 结束源码编辑；代码块有未应用修改时提示先保存。 |
| `:wq`、`:x`    | 保存成功后关闭当前源码标签页或结束当前代码块编辑。                                       |

保存失败时不会执行后续关闭。保存过程中切换标签页、工作区或关闭 Vim，
不会误关后来激活的编辑器。

移动、操作符、选择、查找、替换、撤销等使用 Monaco Vim / CodeMirror Vim
提供的绑定。Vim 编辑器获得焦点时，先处理其绑定，应用只处理未被消费的按键；
离开该编辑器后恢复普通快捷键。中文输入法的组合输入不会交给 Monaco Vim 处理。
