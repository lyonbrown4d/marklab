Getting started

Marklab is a local-first Markdown workspace. Your notes stay in your folders. Write in rich text or source, and use Git when you want version history.

Open a workspace

Section titled “Open a workspace”
  1. Download and install Marklab.
  2. Open the app and choose a local folder from the workspace menu.
  3. Open or create a Markdown note in the file list.

You can use an existing notes directory or a Git repository.

Write a note

Section titled “Write a note”

Type in the editor. Use the editing-mode control in the toolbar to switch between rich text and Markdown source.

Save with ⌘S on macOS or Ctrl+S on Windows and Linux. Your notes remain ordinary Markdown files, ready to back up, sync, or open in another editor.
