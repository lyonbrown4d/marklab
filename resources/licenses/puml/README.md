# PUML

`puml` 0.2.6 renders PlantUML diagrams inside the Rust backend. CLI and URL include
features are disabled.

Source: https://github.com/alliecatowo/puml

`LICENSE` and `THIRD_PARTY_NOTICES.md` are copied unchanged from the published
Cargo package. The latter covers the icon data embedded by the renderer.
`LICENSE-APACHE` contains the Apache 2.0 terms for the Material Design icon data.
