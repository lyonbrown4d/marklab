# 链接与地图

链接让一篇笔记通向另一篇笔记。
地图用文件节点和连线呈现工作区中的关联，帮助你沿着上下文阅读。
本指南各章之间的链接，就是可直接探索的示例。

## 写一条相对链接

同一文件夹中的页面，可以用文件名作为链接目标：

```markdown
[写作与编辑](01-Writing.md)
```

这是实际可打开的链接：[写作与编辑](01-Writing.md)。
路径相对于当前文件所在的文件夹，而不是应用安装目录。
链接文字可以更换；括号中的路径必须对应真实文件。
文件名包含空格时，可以用 `%20` 表示空格。

## 连接不同文件夹

`../` 表示上一层文件夹。例如，笔记在子文件夹中时，
可用 `../` 再加上目标文件名或文件夹路径，指向上层的笔记。
移动或重命名文件后，检查原有链接，避免留下失效路径。
普通相对 Markdown 链接就足以连接页面，无需额外配置。

## 打开链接

在编辑模式或源码模式中，按住 Ctrl（Windows/Linux）或 Command（macOS）点击链接，进入目标文件。
编辑模式中的普通点击用于编辑；开启只读浏览后，工作区链接仍需按住 Ctrl 或 Command 点击。
打开后，检查标签页和文件路径，确认进入了预期页面。

## 在地图中查看

1. 点击顶部「地图」入口，打开工作区地图。
2. 找到指南页面对应的节点。
3. 选择节点，查看路径、关联链接和 Markdown 元数据。
4. 双击可打开的文件节点，跳转到页面。
5. 回到「文件」视图继续写作。

地图适合观察关系；文件列表适合按文件夹定位内容。
没有链接的笔记也可以存在，不必为了连线给每篇笔记添加链接。
