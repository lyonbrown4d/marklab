# 同步、历史与导出

WebDAV 用于在本地工作区与远端文件夹之间同步。
本地历史用于查看文件以前保存的版本；导出用于生成可分享的文档。
开始同步前，确认打开的是 [文件夹工作区](04-Workspaces.md)。

## 第一步：添加 WebDAV 连接

1. 打开设置中的「同步与存储」。
2. 添加连接，填写名称、服务端地址、基础路径和认证信息。
3. 测试连接，检查是否成功，再保存。

连接配置可以重复使用，但每个工作区仍需单独绑定。
使用仅会话凭据时，关闭 Marklab 后需要重新提供认证信息。
不要把密码或应用令牌写入笔记。

## 第二步：绑定当前工作区

1. 在工作区菜单或同步中心中打开 WebDAV 绑定配置。
2. 选择已保存的连接。
3. 指定这个工作区使用的远端文件夹，确认绑定。
4. 打开同步中心，选择立即同步。

留意进度、完成状态和错误提示，必要时取消操作。
配置绑定后，仍应主动查看同步结果，不要把本地保存等同于已同步。
连接失败时先检查配置和网络，再重试。

## 发生冲突时

两端都修改了同一文件，或删除与修改相冲突时，同步中心会提示冲突。
打开处理同步冲突，逐个选择文件，并比较「当前本地版本」与「已保存的远端版本」。
远端冲突副本会保留；替换本地内容前，会备份被替换的本地内容。
对话框会显示远端副本路径，便于检查。

- 保留本地：选择「使用当前本地版本」。
- 保留远端：选择「使用远端版本」。
- 合并内容：先编辑本地文件完成合并，再选择使用当前本地版本。

选择会立即在本地生效；然后再次同步，才会把选择应用到远端。
选择已删除的版本会删除文档，需要确认删除。
无法预览的二进制或大文件，先检查实际文件再选择。
如果版本发生变化或处理失败，刷新版本并重新比较。

## 本地历史

打开文件的「时间线」，选择一个保存版本并预览与当前文件的对比。
确认需要恢复后，选择恢复；当前文件会被该保存版本替换。
删除版本或清空时间线会永久移除相应历史记录。
时间线为空时，表示当前没有可供恢复的本地历史版本。

## 导出当前文档与工作区

当前文档可通过导出操作生成 PDF、Word 或 HTML。
选择输出位置，等待完成；出现错误时查看提示，导出进行中可取消。
需要把多篇笔记组合成一本完整文档时，使用「导出工作区」。
选择章节、调整顺序，检查预览，再设置格式、纸张、页边距等选项并导出。
导出后的文档用于阅读或分享，不会代替原来的 Markdown 文件。

## 完成检查

- [ ] 查看同步是否完成或有待处理冲突
- [ ] 处理冲突后再执行一次同步
- [ ] 恢复历史前先比较内容
- [ ] 打开导出文件检查结果
