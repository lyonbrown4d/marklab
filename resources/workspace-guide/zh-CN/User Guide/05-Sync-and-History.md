# 同步、历史与导出

| 功能        | 用途                     | 入口                                 |
| ----------- | ------------------------ | ------------------------------------ |
| WebDAV 同步 | 对齐本地与远端工作区文件 | 同步与存储设置、工作区菜单、同步中心 |
| 本地历史    | 比较或恢复之前保存的版本 | 文件时间线                           |
| 文档导出    | 生成阅读与分享文件       | 当前文档导出、导出工作区             |

## WebDAV

「同步与存储」中可添加连接，填写地址、基础路径与认证信息，测试后保存。连接可供多个工作区使用，每个[文件夹工作区](04-Workspaces.md)需单独绑定远端文件夹。

同步中心提供立即同步、进度、取消和错误提示。本地保存与远端同步是两个状态。使用仅会话凭据时，关闭应用后需要重新提供认证信息。

## 同步冲突

两端修改同一文件或删除与修改相冲突时，同步中心提供版本比较。

- **保留本地：**选择「使用当前本地版本」。
- **保留远端：**选择「使用远端版本」。
- **合并：**编辑本地内容后，选择当前本地版本。

远端冲突副本会保留，替换前也会备份被替换的本地内容。选择立即在本地生效，再次同步后应用到远端；选择已删除的版本会删除文档。无法预览的文件可通过对话框显示的副本路径查看。

## 本地历史

时间线可预览保存版本与当前文件的差异。恢复会替换当前文件；删除版本或清空时间线会永久移除对应历史记录。

## 导出

当前文档支持 PDF、Word 和 HTML。导出工作区可选择章节、调整顺序、检查预览，并设置格式、纸张与页边距。导出过程中可取消，完成后生成独立文档，原 Markdown 文件仍保留。
