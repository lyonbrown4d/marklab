# 工作区与窗口

工作区决定文件列表、搜索和地图使用哪一组本地文件，顶部显示当前工作区名称。

## 工作区类型

| 类型         | 用途                                   |
| ------------ | -------------------------------------- |
| 默认工作区   | 应用提供的本地起点，首次使用时包含指南 |
| 文件夹工作区 | 管理自己的笔记文件夹与资源             |
| 单文件模式   | 快速查看或编辑一个文件                 |

单文件模式不能新建工作区文件或文件夹，也不能绑定工作区 WebDAV 同步；这些功能需要文件夹工作区。

## 打开与创建

工作区菜单的「新建工作区」按名称和父文件夹创建新文件夹，不覆盖已有同名文件夹。「打开工作区」直接使用已有文件夹，「打开文件」进入单文件模式。

普通打开操作在当前窗口切换工作区。「在新窗口打开工作区」可并排查看不同工作区，「在新窗口打开当前工作区」可再次打开当前目录。多个窗口编辑同一文件时，需留意磁盘变化和保存提示。

## 最近打开记录

工作区菜单列出最近打开的位置，并标识缺失或不可用的路径。记录旁的移除按钮只清理记录，不会删除磁盘文件。

## 会话恢复

再次启动时，Marklab 会尝试恢复工作区与会话。路径不可用时，恢复页面提供重试、定位工作区、打开其他工作区和返回默认工作区。移动文件夹后可定位新路径；外接磁盘重新连接后可重试恢复。
