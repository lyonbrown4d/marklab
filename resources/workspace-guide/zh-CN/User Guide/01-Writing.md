# 写作与编辑

编辑模式直接修改排版后的内容；源码模式显示原始 Markdown；只读浏览适合阅读。文档视图控件用于切换模式，快捷键可在设置中查看。

## 项目简报

### 一次小型发布

**发布目标：**整理已有笔记，形成一份可分享的项目记录。*本周重点*是内容审阅，~~旧版目录~~已归档。文件名为 `release-notes.md`。

> 先保留事实与来源，再整理表达。

- 发布说明
  - 新增功能
  - 已知问题
- 参考资料
- 后续安排

| 文档     | 状态   | 用途     |
| -------- | ------ | -------- |
| 项目简报 | 已定稿 | 说明目标 |
| 发布说明 | 审阅中 | 汇总变化 |
| 参考资料 | 已整理 | 保留来源 |

```typescript
const release = {
  title: '项目记录',
  status: 'review',
  pages: 3,
}
```

## 编辑入口

编辑模式的空行输入 `/` 可插入标题、列表、任务、代码、图表或公式。图片可粘贴或拖入，图片和 PDF 等受支持附件有独立预览。

编辑后可查看保存状态；保存失败时，提示会说明问题。[本地历史](05-Sync-and-History.md)提供之前保存的版本。
