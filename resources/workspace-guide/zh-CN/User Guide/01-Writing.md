# 写作与编辑

从文件列表打开 Markdown 页面，在编辑区直接输入内容。
需要新笔记时，使用工作区菜单中的新建文件操作。
单文件模式下，请先 [打开文件夹工作区](04-Workspaces.md) 再新建工作区文件。

## 选择合适的模式

- 编辑模式：直接编辑排版后的标题、段落、列表和表格。
- 源码模式：查看并修改原始 Markdown，包括链接路径与代码围栏。
- 只读浏览：在排版后的页面中阅读，检查显示效果而不改动内容。

使用文档的视图切换控件选择编辑或源码模式。
需要阅读时可开启只读浏览；图片、PDF 等受支持附件有各自的预览。
只读浏览开启时，先关闭只读状态再修改内容。
需要键盘操作时，到设置中的快捷键页面查看当前绑定。

## 在空行输入 /

在编辑模式的新空行输入 `/`，打开块菜单。
查找标题、列表、任务列表、代码块等项目，再选择要插入的块。
图表与公式的例子见 [更多工具](06-More-Tools.md)。

## 一个可复制的例子

切到源码模式，把下面的 Markdown 复制到自己的笔记：

```markdown
# 本周记录

## 想法

把一个大问题拆成 **三个小步骤**。

- 收集材料
- 写出草稿

- [ ] 检查草稿
- [x] 创建笔记

> 先记录，再整理。
```

回到编辑模式，检查标题、加粗、引用和复选框的显示。

## 图片与保存

你可以粘贴或拖入图片；等待图片导入完成后检查显示结果。
编辑后留意保存状态，遇到保存错误先处理提示，再继续关闭或切换文件。
不要把仍未保存的内容当作已经写入磁盘。
想取回之前保存的版本时，查看 [本地历史](05-Sync-and-History.md)。
