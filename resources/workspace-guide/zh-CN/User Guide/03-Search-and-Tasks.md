# 搜索、任务与页面

当文件增加时，按文件名找页面、按正文找内容、按集合整理页面，分别解决不同问题。
任务列表与 Frontmatter 则帮助你在笔记里记录进度和信息。

## 命令面板

快速单独按两次 Shift，打开命令面板。
也可以使用默认快捷键：macOS 为 Command+P，Windows/Linux 为 Ctrl+P。
快捷键可在设置中修改，以当前显示的绑定为准。
有模态对话框打开时，先关闭对话框再调用面板。

选择适合的搜索模式：

- 快速打开：按文件名或路径定位文件。
- 全文搜索：查找正文中的文字。
- 命令：执行应用操作。
- 设置：定位设置选项。

输入查询后选择结果。全文结果可以帮助你回到匹配内容。
左侧工作区搜索也可用于查找工作区内容。
当前文档内查找适合只搜索正在编辑的页面。

## 所有页面与集合

从命令面板执行打开所有页面，浏览当前工作区的 Markdown 文件。
可以按标题或路径搜索，按文件夹筛选，并选择排序和视图。
「需要关注」集合帮助查找缺失链接、缺失资源或无效锚点的页面。
「已链接」和「结构化」集合可用于寻找已有链接或多个标题的笔记。
如果结果不符合预期，清除筛选；索引正在构建时，等待加载完成。

## 用 Markdown 记录任务

任务写在笔记正文中，不需要单独建立任务数据库。
在编辑模式中勾选复选框，或者在源码模式中修改标记：

```markdown
- [ ] 阅读材料
- [ ] 整理笔记
- [x] 创建工作区
```

`[ ]` 表示未完成，`[x]` 表示已完成。

## Frontmatter：页面开头的元数据

在文件最前面用两行 `---` 包住 YAML：

```yaml
---
title: 每周复盘
tags: [weekly, notes]
status: draft
---
```

编辑器提供结构化字段与 YAML 源码视图。
标题和标签用于描述页面；添加 `status` 不会自动执行任务或流程。
遇到复杂字段时，切换 YAML 源码检查原文。

## 练习

- [ ] 勾选一个任务
- [ ] 查看本页开头的标题和标签
- [ ] 在所有页面中筛选指南所在的文件夹
