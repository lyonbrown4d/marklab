# 搜索、任务与页面

## 发布清单

- [x] 汇总本周变化
- [x] 整理参考资料
- [ ] 审阅发布说明
- [ ] 确定发布日期

任务直接保存在正文中：`[x]`表示完成，`[ ]`表示未完成。编辑模式可通过复选框修改状态。

## 页面属性

本页已包含标题、`guide`与`organization`标签，以及`reference`状态。Frontmatter 位于文件开头，编辑器提供结构化字段与 YAML 源码视图。

```yaml
---
title: 发布说明
tags: [project, release]
status: review
---
```

`status`描述页面状态，不会自动执行流程。元数据也可在[地图](02-Links-and-Map.md)的节点信息中查看。

## 查找内容

| 入口                 | 查找范围                 |
| -------------------- | ------------------------ |
| 快速打开             | 文件名与路径             |
| 全文搜索、工作区搜索 | 工作区正文               |
| 文档内查找           | 当前页面                 |
| 所有页面             | 标题、路径、文件夹与集合 |

命令面板默认使用 Command+P（macOS）、Ctrl+P（Windows/Linux）或快速按两次 Shift 打开，也可搜索命令和设置。「需要关注」集合汇总缺失链接、缺失资源与无效锚点；「已链接」和「结构化」集合分别对应已有链接和多个标题的页面。
