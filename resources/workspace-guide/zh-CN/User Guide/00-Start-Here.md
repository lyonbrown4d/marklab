# 从这里开始

Marklab 将 Markdown 编辑、文件管理与链接地图放在一个桌面工作区中。这份指南本身就是一组互相连接的 Markdown 页面。

## 功能目录

| ------------------------------------------ | ---------------------------------- |
| [写作与编辑](01-Writing.md)                | 标题、强调、引用、列表、表格与代码 |
| [链接与地图](02-Links-and-Map.md)          | 相对路径、页面跳转与笔记关系       |
| [搜索、任务与页面](03-Search-and-Tasks.md) | 搜索入口、任务列表与 Frontmatter   |
| [工作区与窗口](04-Workspaces.md)           | 文件夹工作区、单文件与多窗口       |
| [同步、历史与导出](05-Sync-and-History.md) | WebDAV、时间线与文档导出           |
| [更多工具](06-More-Tools.md)               | Mermaid、数学公式、AI 与终端       |

## 界面入口

顶部工作区菜单提供新建、打开与同步操作。左侧文件列表定位文件，标签页切换已打开的页面。「文件」与「地图」切换文件浏览和关系视图。

快速按两次 Shift 打开命令面板，可查找文件、搜索正文或执行命令。编辑模式中，按住 Ctrl（Windows/Linux）或 Command（macOS）点击页面链接；普通点击用于编辑。
