# 从这里开始

Marklab 把 Markdown 写作、文件管理和链接地图放在一个桌面工作区中。
你的笔记是本地文件；不需要先配置同步或 AI 才能开始写作。
在默认编辑模式中，按住 Ctrl（Windows/Linux）或 Command（macOS）点击指南链接打开页面；普通点击用于编辑。

## 三分钟上手

1. 在左侧文件列表中打开本页。
2. 在下方「我的第一条笔记」中写一句话。
3. 切换到源码模式，看看标题和任务列表对应的 Markdown。
4. 回到编辑模式，勾选一个任务。
5. 打开 [写作与编辑](01-Writing.md)，继续练习。

## 我的第一条笔记

今天我想记录：

- [ ] 写下一个想法
- [ ] 试用编辑与源码模式
- [ ] 打开一个指南链接

你可以直接修改这些练习。它们会和其他笔记一样保存。

## 认识界面

顶部工作区名称旁的菜单提供打开、新建和工作区同步等操作。
左侧用于浏览文件；打开的文件会出现在标签页中。
「文件」与「地图」入口让你在列表和关系视图之间切换。
命令面板可以查找文件和执行命令：快速按两次 Shift 即可打开。

## 这也是你的工作区

指南随应用提供，用来帮助你第一次上手。
这些 Markdown 文件没有特殊保护；可以修改、重命名、移动或删除。
你的修改和已有文件不会被指南初始化覆盖。
删除指南后不会被强制重新创建，所以保留想继续参考的章节即可。
如果移动页面，记得检查相对链接是否仍指向正确位置。
