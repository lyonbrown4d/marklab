# Welcome to Marklab

A workspace for local Markdown notes, linked ideas, and everyday writing.

Open the [Marklab User Guide](User%20Guide/00-Start-Here.md) with Ctrl-click (Windows/Linux) or Command-click (macOS). These pages contain ready-made examples of formatted text, tasks, metadata, diagrams, and equations.

- [Writing](User%20Guide/01-Writing.md): formatted editing and Markdown source
- [Links and the map](User%20Guide/02-Links-and-Map.md): connections between notes
- [Workspaces and windows](User%20Guide/04-Workspaces.md): folders, recent locations, and separate windows

The guide is made of ordinary Markdown files. It can be edited, moved, or deleted; deleted pages are not automatically recreated.
