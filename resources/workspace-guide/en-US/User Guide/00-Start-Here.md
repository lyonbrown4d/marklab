# Start here

Marklab brings Markdown writing, file browsing, and a map of your links into one desktop workspace.
Your notes are local files. You can start writing before configuring sync or AI.
In the default editing mode, hold Ctrl (Windows/Linux) or Command (macOS) while clicking a guide link to open its page. A plain click is for editing.

## Get started in three minutes

1. Open this page from the file list on the left.
2. Write a sentence under “My first note” below.
3. Switch to source mode to see the Markdown for headings and tasks.
4. Return to editing mode and check off a task.
5. Open [Writing and editing](01-Writing.md) for the next exercise.

## My first note

Today I want to remember:

- [ ] Write down an idea
- [ ] Try editing and source modes
- [ ] Open a guide link

You can change these exercises directly. They save just like your other notes.

## Find your way around

The menu beside the workspace name offers open, create, and workspace sync actions.
Use the left sidebar to browse files; opened files appear in tabs.
The Files and Map controls let you switch between the list and relationships.
The command palette finds files and runs commands. Quickly tap Shift twice to open it.

## Make this workspace yours

The guide comes with the app to help you get started.
These Markdown files have no special protection. Edit, rename, move, or delete them.
Guide initialization does not overwrite your changes or existing files.
Deleted guide pages are not forcibly recreated, so keep the chapters you want to reference.
If you move a page, check that its relative links still point to the right files.
