# Workspaces and windows

Your workspace determines which files you browse, search, and see on the map.
Check the workspace name at the top before making changes.

## Three ways to work

- Default workspace: the app's local starting point, including this guide on first use.
- Folder workspace: a folder you choose for your notes and assets.
- Single-file mode: open just one file for a quick read or edit.

Single-file mode cannot create workspace files or folders or bind workspace WebDAV sync.
Open a workspace folder when you need those actions.

## Create or open

New Workspace creates a new folder:

1. Open the workspace menu at the top and choose New Workspace.
2. Enter a workspace name.
3. Choose a parent folder to create and open the workspace.

Creation does not overwrite an existing folder with the same name.
Open workspace selects an existing folder; it does not copy it into the default workspace.
Open File enters single-file mode.

## Current window or new window

An ordinary open action switches the workspace in the current window.
To view two workspaces at once, choose Open Workspace in New Window.
To see the current workspace in another window, choose Open Current Workspace in New Window.
Wait for the result; if opening fails, check the message and retry.
When editing the same file in multiple windows, watch for disk changes and save messages.

## Restart and recover a path

Marklab tries to restore the previous workspace and session.
Restoration can fail if a folder moved, a drive is disconnected, or permissions changed.
The recovery page offers these actions:

- Retry restore: try again once the path is available.
- Locate workspace: select the previous workspace at its new location.
- Open another workspace: continue in a different folder.
- Return to default workspace: go back to the app's local starting point.

Check the drive and path, then choose the recovery action that fits.

## Recently opened

The workspace menu lists recently opened locations and marks missing or unavailable paths.
Use the remove button beside an entry to clear a location you no longer need.
Removing an entry only clears the record; it does not delete workspace files from disk.
