# Links and the map

Relative Markdown links connect workspace notes. These guide chapters already form a small network on the map.

## A link in Markdown

```markdown
[Writing and editing](01-Writing.md)
```

The rendered link opens [Writing and editing](01-Writing.md). Its path is relative to this file's folder. `../` reaches the parent folder, as in [Workspace home](../Home.md); `%20` represents a space in a path.

Ctrl-click (Windows/Linux) or Command-click (macOS) opens the target in editing, source, or read-only browsing mode. Moving or renaming a file can break links that still use its old path.

## On the map

Choose **Map** to see workspace files and connections. Selecting a node shows its path, links, and metadata; double-clicking an openable file node opens the page. **Files** returns to folder navigation.

This page connects to [Search, tasks, and pages](03-Search-and-Tasks.md) for finding notes and [More tools](06-More-Tools.md) for diagrams. Mermaid arrows describe a diagram; Markdown links create connections between files.
